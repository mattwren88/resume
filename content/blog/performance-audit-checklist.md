# A Fast Performance Audit Checklist for Small Teams

Performance work does not need to be overwhelming. A focused checklist can reveal your highest-value fixes quickly.

## Start with Core Web Vitals

Measure Largest Contentful Paint, Cumulative Layout Shift, and Interaction to Next Paint on key pages.

## Optimize heavy assets

- Compress and properly size images.
- Remove unused JavaScript and CSS.
- Delay non-critical scripts.

## Validate real-world behavior

Lab scores are useful, but also test on slower devices and connections to confirm user experience improvements.

Ship the biggest wins first, then iterate.
