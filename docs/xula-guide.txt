XULA Component Guide
Catalog
Adds a single sticky button that links to a catalog entry and floats on the side as you scroll.
How to enable Check Add Catalog Sticky Link (College Landing) under Page Options.
Fields / Parameters
	•	Label (text, required) – Text shown on the button.
	•	Type (radiobutton, required) – Choose Internal, External or None.  • Internal reveals a page, file or symlink selector  • External reveals a URL field  • None disables the link
Rendered Output A fixed button on the page edge. Clicking it opens the selected asset or URL.

Tagline
Displays a full-width colored bar with a bold main heading and optional supporting text.
How to enable Check Add Tagline (College Landing) under Page Options.
Fields / Parameters
	•	Header (text, required) – Main tagline text in large font.
	•	Sub Text (rich text, optional) – Additional paragraph beneath the header.
Rendered Output A centered header and subtext appear in a full-width banner at the top of the page.

Banner: Full Width Image and Overlay Text
Shows a full-width background image with centered overlay text and an optional button.
How to enable Under Page Options, check Add Banner and select Banner w/ Full Width Image and Overlay Text.
Fields / Parameters
	•	Image (asset, required)
	•	Alternative Text (text, required)
	•	Eyebrow Text (text, optional)
	•	Header (text, optional)
	•	Subheader (rich text, optional)
	•	Button Label (text, optional)
	•	Button Link (page selector or URL, appears when label is set)
Rendered Output The chosen image fills the banner. Overlay text and an optional button appear centered on top.

Banner: Overlay Text
Shows a full-width background image with a side panel overlay containing text and an optional link.
How to enable Under Page Options, check Add Banner and select Banner w/ Overlay Text.
Fields / Parameters
	•	Image (asset, required)
	•	Mobile Image (asset, optional)
	•	Alternative Text (text, required)
	•	Header (text, optional)
	•	Content (rich text, required)
	•	Link Label (text, optional)
	•	Link Target (page/file selector or URL, appears when label is set)
Rendered Output A colored panel overlays one side of the full-width image, showing header, content and a clickable link.

Banner: Optional Sub Menu
Shows a full-width image with a side panel that lists a title and links for quick access.
How to enable Check Add Banner and select Banner w/ Optional Sub Menu. Then set Add banner sub menu? to Yes.
Fields / Parameters
	•	Image (asset, required)
	•	Alternative Text (text, required)
	•	Banner Title (text, optional)
	•	Add banner sub menu? (radiobutton, required)  • Yes reveals Sub Menu settings  • No hides them
	•	Sub Menu – Label (text, required)
	•	Sub Menu – Links (group, repeatable)  • Label (text, required)  • Type (radiobutton, required) – Internal or External  • Link (page/file selector or URL, required) 
Rendered Output A side panel on the banner displays the sub menu title with each link as a collapsible item.

Slider
Displays a full-width rotating carousel of images with arrows and pagination dots.
How to enable Under Page Options, check Add Banner and select Slider.
Fields / Parameters
	•	Slides (group, repeatable)  • Image (asset, required)  • Alternative Text (text, required)
Rendered Output A carousel of slides showing selected images. Users navigate with arrows or dots; slides may auto-advance.
Note: Powered by the rbtSlider jQuery plugin.

Background Video
Plays a full-width video in the banner area on loop, muted and autoplaying.
How to enable Under Page Options, check Add Banner and select Background Video.
Fields / Parameters
	•	Video File (file asset, required)
	•	Video Alternative Text (text, required)
Note: Defined in a repeatable Banner group, but only the first video is used.
Rendered Output An HTML5 video element covers the banner area, set to autoplay, loop, and muted. If unsupported, the first frame displays.

Banner: None
Disables the banner altogether so the page content begins immediately below the header.
How to enable Under Page Options, check Add Banner and select None.
Fields / Parameters None. All banner fields are hidden.
Rendered Output No banner section appears.

Subnavigation
Inserts a secondary navigation bar using a pre-built block, positioned above or below the banner.
How to enable Check Add Subnavigation under Page Options.
Fields / Parameters
	•	Sub Navigation (block, required) – Choose a navigation block from _blocks/navigation.
	•	Sub Navigation Location (radiobutton, required)  • Above Banner places it between header and banner  • Below Banner places it immediately below the banner
Configure Menu Edit the chosen block in _blocks/navigation to define dropdown items and links.
Rendered Output A horizontal menu bar shows links from the selected block at the chosen position.

Subheader
Adds a full-width section below the banner with a heading and supporting content.
How to enable Check Add Subheader (Subpage) under Page Options.
Fields / Parameters
	•	Title (text)
	•	Content (rich text)
Rendered Output A full-width bar under the banner shows the title centered above the content.

Sidebar(s)
Adds one or two side panels alongside main content for navigation, images or other widgets.
How to enable Check Add Sidebar(s) under Page Options.
Fields / Parameters
	•	Sidebar(s) Location (radiobutton, required)  • Left Sidebar Only  • Left and Right Sidebars
	•	Sidebars Style (dropdown, required when two sidebars) – Wide or Narrow
	•	Sidebar Title (text, optional)
	•	Override Folder Setup (checkbox) – Use this page’s sidebar settings instead of inherited ones
	•	Side Navigation (block, required) – Choose a navigation block for a collapsible menu
	•	Image Above Navigation (file, optional; 150×150)
	•	Image Alt Text (text, required if image is set)
	•	Sidebar Content Row (group, repeatable) – Add custom HTML, links or widgets below the menu
Rendered Output A vertical panel (left and optionally right) frames the main content. It shows the title, optional image, a collapsible link menu, and any extra content rows.

Head Scripts
Provides a page-level option to insert custom code into the section before the page loads.
How to enable Check Add Head Scripts under Page Options.
Fields / Parameters
	•	Add Scripts? (checkbox, required)
	•	Scripts (textarea, required when enabled) – Enter inline tags or other head-level markup
Rendered Output Inserts your scripts directly into the HEAD SCRIPTS region of the HTML template just before .
HERO Content Rows
High-impact, full-width sections intended for prominent placement near the top of a page. Often used for storytelling, branding, or emphasis.
Each HERO row uses a type dropdown selection within the rows group and reveals different fields.
HERO – Feature Tile with Image
A flexible tile-style component that features an icon, text, image, and link, all wrapped in a responsive layout. Ideal for directional CTAs or highlighting specific services.
How to Enable: Set type = grid-icons-links in a rows entry.
Fields / Parameters:
	•	icon (Shared Field: Font Awesome Dropdown) 
	•	title (Text) 
	•	wysiwyg (WYSIWYG Content) 
	•	image, alt-text (Required) 
	•	imagePosition (Radio: left/right) 
Rendered Output:  A single-column layout with text content, image, and icon placed depending on imagePosition. Image aligns left or right and icon overlays into the corner. Button link wraps the full block.
HERO – Featured Content
Used to pair a large block of styled text with a full-width image and optional CTA link. Frequently used to lead into a story or program highlight.
How to Enable: Set type = fcontent in a rows entry.
Fields / Parameters:
	•	heading (Text) 
	•	content-w (WYSIWYG Content) 
	•	image (Required), alt 
	•	links (Shared Field: Link) 
Rendered Output:  Large bold heading above a rich text body, aligned next to or above a full-width image depending on screen size. Optional button below.
HERO – Featured Text with Image
Pairs bold headline text and paragraph content with an image. Good for short introductions or lead-ins with visual impact.
How to Enable: Set type = featured-text-image in a rows entry.
Fields / Parameters:
	•	featured-text-image/heading (Text, Required) 
	•	featured-text-image/content (WYSIWYG, Required) 
	•	featured-text-image/image, image-alt 
Rendered Output:  Headline and content are shown left or right of the image depending on template style. Layout adapts responsively.
HERO – Featured Tiles
Displays a series of tile-style feature blocks (e.g., Yellow or Green) each with its own link, icon, heading, and body text.
How to Enable: Set type = featured-tiles in a rows entry.
Fields / Parameters:
	•	Repeating feature-tile groups (Min: 1) 
	•	style (Radio: Yellow or Green) 
	•	link-type (Radio: Internal, External, No Link) 
	•	internal or external (Page or URL) 
	•	heading, content (WYSIWYG) 
	•	button (Shared Field: Required) 
Rendered Output:  Tiles arranged in grid layout with color style based on the selected theme. Each tile is fully clickable with hover effects.

	•	four-grid-quote/top-right (Shared Field: Quote)

Rendered Output:  Four quadrant layout styled as a grid. Quote and links are styled with spacing and hover effects. Responsive layout stacks to single column on mobile.

MEDIA – Image Link Matrix
Displays a grid of full-width linked image cards with overlaid captions. Ideal for visually guiding users to key landing pages, program hubs, or feature areas using strong visuals.

How to Enable:  Set Type = MEDIA – Image Link Matrix in a rows entry.

	•	Repeating Item group (Min: 1, Max: 6) 
	•	Image (File asset, Required)

The image is wrapped in an anchor (<a>) and fills its column width responsively. Layout adapts to smaller breakpoints to ensure mobile responsiveness.

MEDIA – Stories Carousel
An interactive carousel showcasing categorized news stories from the News site. Each story card features a category label, headline, summary, and read-more link alongside a dynamic background image. A rotating display allows users to toggle between categories like Student Life, Research, Academics, and Community Engagement.

How to Enable:  Set Type = Stories Carousel in a rows entry.
Fields / Parameters:
	•	heading (Text – Optional)
	•	All content is auto-populated using Velocity queries from the News site. No manual entry of stories is required.
Content Logic:
	•	Uses Cascade CMS's query API to fetch the latest post from each of the following categories: 
	•	Student Life
	•	Research
	•	Academics
	•	Community Engagement 
	•	Pulls from metadata values:
	•	title
	•	summary
	•	category
	•	link
	•	Image logic follows this hierarchy:
	•	Banner image (if banner/display == Yes)
	•	Fallback to addImage field
	•	Default placeholder (if no images found)
Rendered Output: The section displays in a two-column layout: the left side contains the carousel content for each category, and the right side displays the corresponding image. Below, category icons allow switching between tabs. On mobile, this layout stacks vertically with tappable thumbnails. Each slide includes the story title, summary (if provided), and a “Read More” CTA. Images update dynamically with each slide change.
Media – Cards
Displays a set of content cards in a responsive grid. Each card can contain a heading, optional descriptive text, and an optional button-style link. A global toggle allows all cards in the set to include an image above the heading, which enhances visual appeal and supports varied content presentation. The layout adjusts gracefully for smaller screens.

How to Enable:  Set the Type field in a rows entry to Media – Cards.
Fields / Parameters:
	•	Media – Cards (Shared Field: Components/Cards)
	•	Add Images (Checkbox) — When selected, activates image-related fields for each card. 
	•	Card (Group – repeatable)
	•	Heading (Text) — Required; the card title.
	•	Text (WYSIWYG) — Optional descriptive content below the title.
	•	Image (File) — Required if “Add Images” is checked; displayed at the top of the card.
	•	Image Alt Text (Text) — Required if “Add Images” is checked; brief description for accessibility.
	•	Link (Shared Field: Link) — Optional; if provided, displays as a button below the text.
Rendered Output: The component outputs a <div class="cent-announcement-cards cent-container"> containing multiple <div class="cent-card"> elements. Each card may include an <img> at the top (if enabled), followed by an <h2> for the heading, optional rich text in a <div>, and a button-style <a class="cent-read-more"> link if a URL is provided. Styling ensures consistent spacing, card borders or shadows, and responsive stacking for mobile displays.
Media – Video / Photo
Displays a two‑column media block: the left column shows a large background image with an overlaid play button that opens an MP4 video in a lightbox; the right column shows a companion photo. On smaller screens the columns stack vertically while preserving the play‑to‑lightbox behavior.

How to Enable:  Set the Type field in a rows entry to Media – Video / Photo.
Fields / Parameters:
	•	Video / Photo (Group) 
	•	Video (File – required) — MP4 source used by the lightbox player. (Help text: “The video needs to be in MP4 format.”)
	•	Video Placeholder (File – required) — Background image behind the play button in the left column (acts as the poster/teaser image).
	•	Image (File – required) — Background image for the right column.
Rendered Output: The component outputs a wrapper with a .row containing two .column elements. The left column uses the Video Placeholder as a CSS background with a centered play button; clicking it launches the Video in an Afterglow lightbox (.afterglow link and .afterglow-lightboxplayer video). The right column renders the Image as a CSS background. Spacing, overlay tint, and button styling are handled by site styles; the layout collapses into a single column on narrow viewports for responsive display.

The rising textbox animation provides an engaging interactive effect without obscuring the image entirely.

CONTENT Content Rows
Sections designed primarily for delivering structured or narrative information. These rows focus on clarity, accessibility, and flexibility—supporting text-rich layouts, interactive components, and expandable details. Each CONTENT row uses a type dropdown selection within the rows group and reveals fields tailored to its specific format.
CONTENT – Accordion with Text
Displays a vertical list of collapsible items. Each item shows a label; clicking toggles a content panel beneath it. Works well for FAQs and long-form sections where progressive disclosure improves scannability.

How to Enable:
	•	Set the Type field in a rows entry to Content – Accordion with Text.
Fields / Parameters:
	•	Heading (Text) — Optional; section title shown above the accordion.
	•	Accordion (Group – repeatable)
	•	Label (Text) — Required; the clickable title of the item.
	•	Content (WYSIWYG) — Required; rich text revealed when the item is expanded.
Behavior & Notes:
	•	Each item renders as a checkbox‑driven toggle (plus/minus icon swap) for broad browser support
	•	If your theme supplies a background style variable (e.g., a “gray background” switch), the container will receive a corresponding class to adjust styling; otherwise the default (white) style is used.
	•	If an item’s content isn’t already wrapped in a paragraph, the component auto‑wraps it to keep spacing consistent.
	•	Use unique, concise Label text so generated IDs remain unique and accessible.
Rendered Output:
	•	The component outputs a series of .xv-accordion-container blocks (theme class may be appended) containing an .accordion-wrapper with one .tab per item.
	•	Each .tab includes an input[type="checkbox"] (drives the toggle), a <label> showing the Label text and plus/minus icons, and a .tab-content region containing the Content.
	•	Typography and spacing follow the site’s base styles; items stack fluidly on small screens.
Content – Content
Displays one to three text columns with an optional section heading. Each column can include a short column header and rich-text content. The layout shifts responsively (one column on small screens; two or three columns on larger screens) and can adopt an alternate background color to visually separate the section.

How to Enable: Set the Type field in a rows entry to Content – Content.
Fields / Parameters:
	•	Background Color (Radio: White / Gray / Dark Gray) — Optional; sets the section’s background style.
	•	Heading (Text) — Optional; section title displayed above the columns.
	•	Content Column (Group — repeatable; min 1, max 3)
	•	Header (Text) — Optional; small heading for the column.
	•	Content (WYSIWYG — required) — Main body copy for the column.
Rendered Output: Outputs a row wrapper that applies the chosen Background Color and contains the optional Heading followed by 1–3 column containers. Each column renders the Header as a subheading above the WYSIWYG Content. The grid uses equal-width columns (two-up or three-up at larger breakpoints) and stacks into a single column on narrow screens for readability.
CONTENT – Page Introduction
Introduces the page with a prominent title, optional subtitle, rich text, and an optional image. When an image is supplied, the layout becomes a two‑column split (text left, image right). On smaller screens, columns stack vertically for readability.

How to Enable: Set the Type field in a rows entry to CONTENT – Page Introduction.
Fields / Parameters:
	•	Page Title (Text) — Required; displayed as the main H1.
	•	Subtitle (Text) — Optional; italic subheading beneath the title.
	•	Content (WYSIWYG) — Required; body copy supporting the intro.
	•	Image (File) — Optional; if provided, appears in the right column.
