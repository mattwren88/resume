Site Setup
	•	You can manage your site’s header, footer and other shared content within the Site Setup block, located in the “_cms” directory of your main site. 
	•	All logos, text and navigation items are fully editable and currently populated with placeholder content for testing. 
	•	Global links have been configured manually to provide maximum flexibility across a variety of use cases.
	•	The Sock is managed globally and shows on all pages by default but can be disabled on specific pages if needed.
Page Types & Components
As previously noted, we implemented the majority of components/patterns as reusable blocks, while implementing them directly on the page on the homepage - and in a few other areas as stated below - where they were best suited based on our established practices and expertise. Each component is set on the Row and can be rearranged as noted below.

Key
🔒 = fixed  ↕️ = rearrangeable  🧱 = block  📄 = page
Home Page
Hero 📄🔒
A full-page banner fixed at the top of your homepage. Upload a responsive image (or MP4 video) and enter your two-line H1 via the Title and Title 2 fields—with the second line automatically styled. Configure one primary CTA and up to two secondary CTAs via the link and sLink fields. This hero isn’t part of the row picker; it lives directly on the page.
Goals 🧱↕️
A multi-stage decision tree you can drop anywhere on the page. Start by adding a heading and optional intro text, then define your first level of options as buttons. Each button reveals a second level of choices or a detailed content panel that can include:

	•	Rich text descriptions
	•	Image + quote sections
	•	Primary and secondary CTAs

Built-in “Back” links let users navigate between steps, and you can surface persistent contact links or an “Other Options” list at the bottom for extra guidance. Perfect for any scenario where you need to guide visitors through a structured, step-by-step journey.

Pathways 🧱↕️
A flexible, repositionable card-grid row. Start with an optional section heading and background, then add as many cards as you need—each featuring an icon, a title, and a link. You can also include a catch-all “default” card at the end to guide visitors who aren’t sure where to go.
Stats 🧱↕️
An image-backed, repositionable row for showcasing key figures. First, upload a background image. Then add up to three stat items—each with a large “big text” value (number, percentage, ratio, etc.) and a concise caption below. The module automatically lays them out side-by-side over the image, with separators, for a data-driven visual highlight.
Support 🧱↕️
A split-row block you can drop anywhere to surface your help resources and people. On the left, enter your main heading, then add a horizontal list of support links and a prominent primary CTA button. Below that you can list contact methods (email, phone, etc.) with optional labels. On the right, toggle on the image slider to upload one or more slides—each slide shows a graphic or photo with its caption or quote—complete with dots for navigation. It’s perfect for pairing your support channels with a dynamic showcase of faces, places, or success stories.
Pattern Page
Hero 📄🔒
A full-width banner at the top of the page that displays a selected responsive image with an overlaid H1 title. Managed via the Hero fields (image and title) and fixed in place—you can’t move it into another row.
2 Columns 🧱↕️
A two-panel layout applied as a row you can reposition. Each panel includes an image, a title (linked if a URL is provided), optional subtitle, and rich-text content. Any configured primary or secondary links display below the panels.
3 Columns 🧱↕️
A three-panel block applied as a row you can reposition. Each column displays an image, a title (linked if a URL is provided), optional subtitle, and rich-text content. Configured primary CTA renders as a button, with any secondary CTAs or links listed afterward.
Accordion 🧱↕️
A set of collapsible panels applied as a row you can reposition. Optionally include a heading and intro, then add multiple toggleable items. Use “Expand All” to open every panel; each panel’s title button reveals its rich content and offers a “Back to top” link.
Carousel 🧱↕️
A horizontal slide-show block you can insert as a row and move around. Add an optional heading and intro, then configure 2–10 slides—each slide displays a responsive image with its caption below. Left/right arrows let visitors navigate through the slides.
Contact Feature 🧱↕️
A split-row block you can reposition. Add a bold heading and intro text, then configure the primary CTA button via the CTA Link field. Below that, stack your contact methods (email, phone, TTY), each with an optional secondary label like “Español” or “TTY.” Toggle on the image option to display a side graphic with its own caption for extra context.
CTA Bar 🧱↕️
A slim, full-width row you can reposition. The left side displays your H2 heading; the right side shows up to three CTAs configured in the Link repeater. For each link, choose its type (Internal page, External URL, Email, or Phone), enter the destination and label, and set the target. The macro auto-formats mailto: and tel: links and renders standard anchors for pages or URLs—perfect for highlighting “Apply Now,” “Contact Us,” or direct-dial options.
​Full-Bleed Image 🧱↕️
A full-width image block you can reposition as a row. Optionally add an H2 heading and intro text above the image, then upload your graphic via the Source group and enter a caption. The image displays edge-to-edge (inside a <figure>), with the caption shown below for context or attribution.
Full-Bleed Video 🧱↕️
A full-width video block you can reposition as a row. Add an H2 heading and intro text, then in the Video group upload your thumbnail (uses its Display Name for alt text), enter the YouTube video ID, and add an optional caption. The page initially shows the responsive thumbnail with a play overlay; when clicked, it swaps in the embedded video player and plays inline, with the caption displayed below.
Image List 🧱↕️
A card-style list applied as a row you can reposition. Optionally add a heading and intro, then add as many items as needed—each item shows a thumbnail image, a linked title with an optional subtitle, and rich-text content with inline links. Ideal for news teasers, event listings, or any repeatable feature showcase.
Instagram 🧱↕️
A dynamic Instagram feed block you can reposition. Enter your Instagram API endpoint in the API field, then optionally add a heading and intro text. The block pulls your latest posts into a responsive grid of image tiles with fade-in effects. If you add a profile link, it displays as a CTA button (e.g. “Follow on Instagram”) beneath the feed.
Jump Links 📄↕️
A row-level block that auto-builds a “Jump To” menu based on your page’s rows. First, set the menu heading in the Jump Links block. Then, for each row on the page, toggle “Include in Jump Links” and enter its label in the Row Label field. The block will generate anchor links to each selected section—just drag it into place (typically at the top) and it updates itself as you add or remove rows.
Link Cards 🧱↕️
A grid-style block you can reposition. Add an H2 heading, then create as many cards as you need—each shows an image, a linked title, and rich-text content. Cards can include expandable sub-links behind a “+ More” toggle for deeper navigation.
Page Introduction 📄↕️
A customizable intro row you can reposition. Pick your layout—Default text, Quote (with a blockquote, speaker image, name/title), or Icon List (with a subheading and list items that can include icons)—then fill in the corresponding content fields for a polished opening section.
Quote 🧱↕️
A standalone quote block you can reposition as a row. Add an optional H2 heading and intro text, then enter your multi-line quote and fill in the source’s name and attribution. Renders a styled full-width blockquote with a footer showing the speaker’s name and role.
Statistics 3-Up 🧱↕️
A three-column block you can reposition as a row. Optionally add a heading and intro text, then configure up to three stats—each stat shows a large “big text” number, a descriptive caption below, and an optional link for more info. Ideal for highlighting key figures or KPIs in a clean, side-by-side layout.
Story Display 🧱↕️
A two-part, repositionable row for highlighting a real-world story. In the top section, upload a portrait image and enter a standout quote with the speaker’s name and credentials. In the bottom section, add a caption title, rich-text body, an optional list of related links, and primary/secondary CTA buttons for deeper engagement.
Tabs 🧱↕️
A rearrangeable row of tabbed panels you can drop anywhere. Each tab displays a header label and a supporting image, plus one of two content types:
	•	Contact: toggle phone, address and hours lists, with an optional “Learn more” link
	•	Manual: a fully rich-text editor for paragraphs, lists, headings or links
Clicking a tab title swaps in its panel. Perfect for spotlighting multiple locations, FAQs or other split-view info.
WYSIWYG 🧱↕️📄
A fully editable rich-text component you can add as a WYSIWYG Block inside any row (rearrangeable) or drop directly onto the page. Use the editor to insert headings, paragraphs, lists, links or embedded media—ideal for any freeform content that doesn’t fit a predefined pattern.
Notes
Links
	•	All link fields are standardized for consistency.
	•	Most links are required and must include a label.
	•	Links can be designated as optional if the HTML code allows.
Images
	•	Each image field should have recommended dimensions.
	•	Alternative text is managed via the file’s Display Name. When an image file is reused, its Display Name remains the same.
	•	The Display Name is optional; decorative images should have no alternative text.
	•	Images can be designated as optional if the HTML code allows.
Responsive Images
	•	Certain components are coded to leverage multiple image sizes for optimal performance.
	•	To create a responsive image, use the “Responsive Image” button (in the Add Content menu) specific to the component/field. This ensures that 2 additional correctly sized versions are generated.
	•	To use a responsive image, select the original (largest) image uploaded via the “Responsive Image” from the Add Content menu; the smaller versions are linked automatically.
	•	Non-responsive images will still function but may not produce the best results.
Creating Pages
When creating pages in the CMS, you can follow these steps for a smooth process:
	•	Plan Your Page Structure
	•	Identify which components you need.
	•	Determine whether each component is inline or a block.
	•	If a component is a block, create it first via Add Content → Blocks.
	•	Prepare Your Images
	•	Decide which images you’ll use and whether they need to be responsive.
	•	If you require responsive images, upload them via Add Content → Responsive Images so the system generates the correct sizes automatically.
	•	Assemble Your Page
	•	With all components and assets in place, create your rows, insert your blocks and/or inline content. Rearrange as needed and preview.
