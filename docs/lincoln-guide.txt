Publications – Editor Guide
Lincoln University

This short guide explains how Publications work, how to add new items, and how to troubleshoot common issues. It’s written for editors and site managers.

1. What is a Publication?
A Publication is either a Page or a File (e.g., a PDF) that appears on the Publications listing. Each item shows a thumbnail, title, month/year, description, and a badge indicating whether it’s a Page or a File. Visitors can search, filter by category, and sort by Title or Date.

Figure 1. Publications listing with search, category filter, and sort controls.
2. Editor Quick-Start (Checklist)
	•	Go to Add Content → Pages → Publication.
	•	Set Publication Type (Page or File).
	•	Fill Title, Description, Publication Date (required), and Publication Thumbnail (required).
	•	Optional: choose a Publication Category.
	•	If Type = File, pick the file in the Publication field.
	•	Submit → Publish.
	•	Verify it appears on the Publications page and the badge reads Page or File as expected.
3. When to Choose Page vs File
Page – choose when you need a full page with hero/rows/related links.
File – choose when the card should open a PDF (or other file) directly.
Already have a PDF? Convert the file’s Metadata Set to Publication and fill the fields—no page needed.
4. How to Add a Publication
Option A — Publication as a Page
	•	Go to Add Content → Pages → Publication.
	•	Fill out Title and Description.
	•	Publication Type: choose Page.
	•	Publication Date: set the release date (required; used for sorting and the Month YYYY display).
	•	Publication Thumbnail: choose an image (required).
	•	Optional: set Publication Category.
	•	Add content in the usual page rows/blocks and Submit/Publish.
Option B — Publication that links directly to a File
There are two equally valid ways:
B1. Create a Publication page that points to a file
	•	Add Content → Pages → Publication File.
	•	Publication Type: choose File.
	•	Use the Publication field to pick your PDF/asset.
	•	Complete required fields (Title/Description/Publication Date/Thumbnail).
	•	Optional: set Publication Category.
	•	Submit/Publish. Clicking the card opens the file directly.
B2. Convert an existing file into a Publication
	•	Open the existing file asset (e.g., a PDF).
	•	Change its Metadata Set to Publication.
	•	Fill Publication Date, Publication Thumbnail, and (optional) Publication Category. Confirm Title/Description.
	•	Submit/Publish. The file will now appear with a File badge and link directly to itself.
5. Where Categories Come From (and How to Add One)
The By Category dropdown is auto-built from the category values on your items. To add a new option for editors, update the Publication Category shared field (admin-only). Use consistent names (e.g., “Research”) to avoid duplicates.
6. Page-Level Settings (on the Publications Index Page)
	•	Items per page – how many cards appear before pagination.
	•	Default sort – Title or Date (and Asc/Desc).
	•	Asset type restriction – show Pages, Files, or Both.
	•	Pagination style – numbers vs. “Show More.”
	•	Default category – optional pre-filter.
7. Image & Thumbnail Guidance
	•	Thumbnails render square (1:1). Use images at least 600×600 for crisp results.
	•	Provide meaningful Alt Text on page/file images where applicable.
9. Replacing or Updating Publications
	•	Replacing a PDF: upload the new file, then use your normal replace/relationship step so existing links stay intact.
	•	New edition? Create a new Publication with a new Publication Date; optionally link back to the prior version in the description.
	•	Unpublish/archive: unpublish the asset and/or move it out of scope; or use an “Archived” category if you adopt one.

12. Appendix A — Field Map (Editor UI → Listing)
	•	Title / Description: Card heading and summary
	•	Publication Date: Month YYYY label and date sorting
	•	Publication Type: Determines link behavior and badge (Page or File)
	•	Publication (file picker): Target file when Type = File
	•	Publication Thumbnail: Card image (square rendering)
	•	Publication Category: Powers the By Category filter
13. Appendix B — Admin Notes
	•	Categories live in the Publication Category shared field; edits change the dropdown for everyone.
	•	The listing is client-side filtered/sorted; if your library grows very large, consider enabling pagination and/or a JSON-backed feed for performance
